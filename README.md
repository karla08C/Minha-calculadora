# Minha Calculadora

Projeto desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas para praticar conceitos fundamentais de React e JavaScript.

## Funcionalidades

* Operações matemáticas básicas
* Interface amigável
* Atualização dinâmica dos resultados

## Tecnologias

* React
* JavaScript
* CSS

## Objetivo

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em desenvolvimento Frontend, com foco na construção de interfaces interativas e manipulação de estado.
